# padelspot.com

Sends every padelspot.com address (including /invest) to the Padel Spot page on
https://www.emb.org/portfolio/padelspot/. Served by GitHub Pages from branch `site`;
`404.html` is a copy of `index.html` so any path redirects too.

DNS for padelspot.com is at GoDaddy (default nameservers): the four `@` A records point at
GitHub Pages (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) and `www`
is a CNAME to `emiami.github.io`.
